# Large and omitted files

Nothing in the six source folders is over 25 MB (largest kept file: `gallery-courtyard/sunburst-floor.png`, about 5 MB), and there are no video files in them. So no single large file was left out for size. The repo is about 98 MB.

Left out on purpose (box path, size):

| Box path | Size | Why / where it lives |
|---|---|---|
| `/workspace/play-tags/node_modules/` | part of 120 MB folder | Reinstall with `npm install`. |
| `/workspace/play-tags/dist`, `dist1022`, `dist289`, `dist295` | build outputs | Regenerate with `npm run build`. |
| `/workspace/play-tags/deploy/_worker.js` | 4.6 MB | Generated by `deploy/gen.py` from `dist/`. |
| `/workspace/play-tags/deploy/execute.js` | 4.7 MB | Generated Cloudflare deploy payload. Rebuild or use `wrangler pages deploy`. |
| `/workspace/play-tags/.env.production` | small | Env file, not committed. Ask TJ. |
| `/workspace/museum-shared/layout-save-urls.txt` | small | Contains secret save URLs. Never committed. |

Not on the box / not in this repo:
- Hi-res original paintings: not on the box. Ask TJ. Web WebP versions are served from tjm.art (`/play/art/`) and `img.tjm.art` (R2).
- Big textures and ostrich GLBs for previews: live in R2 under `play/preview-NNN/` on img.tjm.art. The small GLBs (`ostrich-robot/*.glb`, under 300 KB each) ARE in this repo.
- Live site media (`/play/media/`) and any videos: not included.
