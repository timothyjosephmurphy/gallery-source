# Story-board plates (#335): blank plates for Writer's story copy

These are blank, textured story-board plates. Gallery draws the story text into `text_rect_uv`, either onto the albedo through a canvas or onto a child plane.
The format follows the courtyard signs (`hq-assets/signs/sign-plate-*.webp`: a flat `PlaneGeometry` with colour+alpha / `_n` / `_r` webp maps, plus a `.phone.webp` tier at half resolution). That is why these are **webp planes, not GLBs**, and no meshopt decoder is needed. `play-tags/src/tags.js` (`brass-plaque`) uses the same plane-plus-texture pattern.
They were generated by `make_plates.py` (numpy/PIL, seed 335, rerunnable), and the contact sheet comes from `contact.py`. Nothing was uploaded, and no Gallery repo was edited.

## Face size and text rect
* Face: **0.45 x 0.28 m** (`PlaneGeometry(0.45, 0.28)`). The texture aspect is 1.6, which matches 0.45/0.28 = 1.607 to within 0.5 %.
* **text_rect_uv (three.js UV, v up, default flipY): u0 0.09375, v0 0.1375, u1 0.90625, v1 0.8625**. The same fractions apply at both resolutions.
* Canvas or pixel space (top-left origin): x 96..928, y 88..552 at 1024x640 desktop size, and x 48..464, y 44..276 at 512x320 phone size.
* In metres from the plate centre: **x -0.1828..+0.1828, y -0.1015..+0.1015** (a text area of 0.366 x 0.203 m).
* At a 1.45 m eye line, cap height should be at least ~12 mm for titles and ~7 mm for body text. At desktop resolution 1 mm is about 2.28 px, so use roughly a 28-34 px title and 16-20 px body on the 1024 canvas.
* Suggested ink per variant: dark `#e9dcc0`, brass `#2a1a0c` (engraved look), enamel `#f3ead6`. These are also in `story-plates.json`.

## Loading (same as the signs)
```js
const tier = isPhone ? '.phone' : '';  const L = new THREE.TextureLoader(), base = 'story-plaques/story-plate-dark';
const map = L.load(`${base}${tier}.webp`); map.colorSpace = THREE.SRGBColorSpace;
const mat = new THREE.MeshStandardMaterial({ map, normalMap: L.load(`${base}_n${tier}.webp`), roughnessMap: L.load(`${base}_r${tier}.webp`), metalness: 0, alphaTest: 0.5 });
const plate = new THREE.Mesh(new THREE.PlaneGeometry(0.45, 0.28), mat);
```
Text, option A (child plane, recommended because the plate textures stay cached and shared): use a canvas sized to the rect (e.g. 832x464 desktop, 416x232 phone) as a `CanvasTexture` on `PlaneGeometry(0.366, 0.203)`. Add it as a child at (0, 0, 0.001) with `MeshBasicMaterial({ map, transparent: true })`. The rect is centred, so no offset is needed.
Text, option B (bake into albedo): draw the albedo image onto a 2D canvas, then `fillText` inside x 96..928, y 88..552 (desktop) or the halved values (phone). Use that canvas as `map`.
In both cases, multiply by `u0..u1` / `v0..v1` if you compute positions from UVs.

## Per-room BRASS plates with Art Deco relief (TJ, Oct 26: brass only for #335)
**Use these 12 room plates for the story plaques.** The dark and enamel variants above are superseded and kept only for reference.
* Script: `make_room_plates.py`. It starts from the `story-plate-brass` maps made by `make_plates.py`, so run that first. Motifs follow `art-deco-style-guide.png`. `contact_rooms.py` builds `preview.png`, which shows all 12 blank plates plus one sample with the text rect outlined.
* The design adds a recessed antique-brass band around the brushed text field. Motifs are raised, polished gold lines with brushed-brass relief bodies, and they have matching normal and roughness detail.
* Deco sits **only** in the top crest band (y < 85 px), the corners (around the four screws), the side bands (x < 93 / > 931) and the bottom frieze (y > 555). A 3 px guard round the text rect is forced clear, so it stays plain brushed brass.
* Unchanged: face 0.45 x 0.28 m, **text_rect_uv u 0.09375-0.90625, v 0.1375-0.8625**, ink `#2a1a0c`, metalness 1, alphaTest 0.5. Loading works exactly as above: set `base = 'story-plaques/story-plate-brass-room-04'` and use the same `_n`, `_r` and `.phone` suffixes.
