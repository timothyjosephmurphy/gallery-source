# #11 The Machine Offers Its Hand — Easel Card — PRIVATE DRAFT
**Title / size / paper:** Half sheet (15×22 in) horizontal · 300 gsm cold press
**One-line beat:** A warm human hand and a pearlescent machine hand reach toward the same unfinished sketch.
**Thumbnail:**
- Lights: machine hand (mostly reserved white) + sketch paper
- Mid: warm flesh hand, loose rainbow sketch
- Darks: background behind the gap between hands
**Palette:** Quin Rose + New Gamboge (human) · Phthalo Turquoise + Ultramarine whisper (machine) · loose rainbow sketch.
**Wash order:**
1. Pencil: both hands, sketch sheet, the gap.
2. Reserve machine hand and sketch paper.
3. Human hand Rose + Gamboge, 2 layers.
4. Loose rainbow sketch strokes.
5. Glaze sketch colors faintly into machine hand (borrowed color, not chrome).
6. Background dark behind the gap, one pass.
7. Optional single iridescent stroke.
**Keep white:** Machine hand body + sketch highlights.
**TJ north star:**
- Hinge: sovereignty includes choosing collaboration.
- Cooler than #3 but warming.
**Don't:** No sci-fi chrome · no red eyes · no menace · hands must not touch.
**Done when:** Both hands read equal-weight and the gap is the focal point.
